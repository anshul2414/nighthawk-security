Quick Start
Running in 30 seconds
🐍 Python 🐳 Docker 🏳️ Windows 
# Clone & run NightHawk
git clone https://github.com/anshul2414/nighthawk-security.git
cd nighthawk-security
pip install -r requirements.txt
python app.py
# Open → http://localhost:5000  (no login required)
# Docker Compose
git clone https://github.com/anshul2414/nighthawk-security.git
cd nighthawk-security && docker-compose up -d
# Open → http://localhost:8080
# Windows one-click
git clone https://github.com/anshul2414/nighthawk-security.git
cd nighthawk-security && run.bat
# Opens → http://localhost:5000
